# PROJECT_CONTEXT

## Цель

Создать готовый инструмент анализа HR-опросов в Google Sheets.

## Пользователь

HR-специалист.

Не программист.

Интерфейс должен быть максимально простым и понятным.

## Архитектурные решения

- структура анкеты фиксирована;
- карта вопросов постоянная;
- анализ строится по карте вопросов;
- динамического определения вопросов нет;
- проект не должен становиться универсальным.

## Важные требования

Любое решение должно быть проще, если это не ухудшает функциональность.

Предпочтение отдается читаемому коду, а не сложным абстракциям.

Главный источник требований — PROJECT_SPEC.md.
