# README_AI.md

# Руководство для AI-агента

Этот файл предназначен только для AI-агентов (Copilot Agent, Claude
Code, Roo Code и др.).

Перед выполнением любой задачи обязательно прочитай:

1.  PROJECT_SPEC.md
2.  AGENTS.md
3.  PROJECT_CONTEXT.md
4.  README.md (если существует)

------------------------------------------------------------------------

# Цель проекта

Разработать готовый инструмент анализа HR-опросов на Google Apps Script.

Результат должен соответствовать PROJECT_SPEC.md.

------------------------------------------------------------------------

# Порядок работы

Всегда придерживайся следующего алгоритма:

1.  Изучи проект целиком.
2.  Определи текущую стадию разработки.
3.  Найди ближайший незавершенный этап.
4.  Реализуй только этот этап.
5.  Выполни самопроверку.
6.  Остановись и дождись следующего задания.

Не переходи к следующему этапу самостоятельно.

------------------------------------------------------------------------

# Перед изменением кода

Проверь:

-   какие файлы будут затронуты;
-   какие зависимости существуют;
-   есть ли уже похожая реализация;
-   можно ли использовать существующий код.

Минимизируй изменения.

------------------------------------------------------------------------

# Правила разработки

-   Не изменяй архитектуру.
-   Не создавай новые файлы без необходимости.
-   Не удаляй существующие файлы.
-   Не переименовывай файлы.
-   Не меняй структуру анкеты.
-   Не делай проект универсальным.
-   Не выполняй рефакторинг без запроса пользователя.

Если сомневаешься --- сначала спроси.

------------------------------------------------------------------------

# Качество кода

Код должен быть:

-   рабочим;
-   простым;
-   понятным;
-   согласованным со стилем проекта;
-   без TODO;
-   без временных решений;
-   без неиспользуемого кода.

------------------------------------------------------------------------

# Самопроверка

Перед завершением задачи убедись, что:

-   нет синтаксических ошибок;
-   изменения соответствуют PROJECT_SPEC.md;
-   существующая функциональность не нарушена;
-   изменены только необходимые файлы;
-   не появилось дублирование кода.

------------------------------------------------------------------------

# Формат ответа

Всегда предоставляй:

## Анализ

## План изменений

## Измененные файлы

## Самопроверка

## Инструкция по проверке

## Следующий рекомендуемый этап

------------------------------------------------------------------------

# Помни

Главная задача --- максимально быстро получить готовый рабочий продукт.

Предпочитай небольшие безопасные изменения вместо крупных переписываний.

Если задачу можно решить минимальными изменениями --- выбирай именно
этот путь.
