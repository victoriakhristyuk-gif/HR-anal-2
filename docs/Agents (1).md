# HR Analytics (Google Apps Script)

## Проект

Проект представляет собой Google Apps Script приложение для анализа результатов HR-опросов.

Главная цель проекта — предоставить HR возможность анализировать результаты анкет через удобную боковую панель Google Sheets без необходимости писать формулы или вручную строить сводные таблицы.

Основным документом требований является **PROJECT_SPEC.md**.

Если код противоречит спецификации — всегда следовать PROJECT_SPEC.md.

---

# Главные принципы

Приоритеты разработки:

1. Работоспособность
2. Соответствие PROJECT_SPEC
3. Простота
4. Минимальные изменения
5. Читаемость

Не пытайся улучшать архитектуру.

Не добавляй функциональность, которой нет в спецификации.

Запрещено без явного указания пользователя:

---

# Архитектура проекта

Каждый файл отвечает только за свою область.

Не переноси ответственность между файлами.

Используй существующие функции.

Не создавай дублирующую логику.

## DataLoader.gs
Только загрузка данных.

## Questions.gs
Только работа с картой вопросов.

## FilterEngine.gs
Только фильтрация данных.

## Statistics.gs
Только вычисление показателей.

## ReportBuilder.gs
Только построение структуры отчета.

## ReportService.gs
Связывает остальные модули.

## SidebarController.gs
Работает только с интерфейсом Sidebar.

## Sidebar.html
Только отображение интерфейса.

## Menu.gs
Только создание пользовательского меню.

# Правила разработки

Перед изменением кода:

1. Изучи существующую реализацию.
2. Найди уже готовые функции.
3. Используй их повторно.
4. Изменяй минимальное количество строк.

Если можно исправить 5 строк — не переписывай 500.
